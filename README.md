# 📖 Project Overview

**Functional Treat** is a **Menu-Driven Python Application** developed to analyze and transform datasets using **1D** and **2D Lists**.

The project demonstrates different Python programming concepts by performing various operations on user data. It provides a simple and interactive interface where users can input data, analyze it, sort values, calculate statistics, filter data using lambda functions, and understand important function concepts through practical implementation.

This project was developed as part of the **Bachelor of Computer Applications (BCA)** practical work to strengthen programming skills and improve understanding of Python functions.

---

# 🎯 Project Objectives

The main objective of this project is to provide a simple data analysis tool while demonstrating the practical implementation of Python functions.

### The project allows users to:

- 📥 Input 1D Dataset
- 📥 Input 2D Dataset
- 📊 Analyze Data
- 📈 Calculate Dataset Statistics
- 🔁 Apply Sorting Techniques
- ⚡ Filter Data using Lambda Function
- 🧠 Understand Recursion
- 📚 Learn Python Function Concepts
- 📖 Display Function Documentation

| Feature | Description |
